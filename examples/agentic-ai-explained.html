What agentic AI is 00:20

The speaker defines agentic AI as intelligent systems that set goals, create action plans and execute multi-step workflows on their own. A chatbot waits for each instruction; agentic AI is like a project manager you hand a goal to.

  • It breaks the task down, picks tools, executes steps, checks its own work and adjusts until the goal is met.

Risks and guardrails 00:52

More autonomy means more ways to go wrong.

Risks
  • Unintended actions
  • Optimising for the wrong goal
  • Access to tools it doesn't need
  • Decisions hard to trace
Guardrails 01:08
  • Permission boundaries
  • Human approval for high-stakes actions
  • Audit logs
  • Clear state tracking

The core loop 02:28

Every agentic system runs the same basic loop.

Four key components 03:06

  • LLM: the brain, generating reasoning and possible plans.
  • Tools: let the agent interact with the world instead of just talking.
  • Memory: a notebook of past actions and context.
  • Orchestration layer: the manager, coordinating everything and controlling access.
